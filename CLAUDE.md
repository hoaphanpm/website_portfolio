# Project Objective

Build a full-stack Product Manager portfolio website based on the requirements in `/docs`.

Use:
- Supabase/Postgres for persistent data
- A reusable database-driven case-study renderer
- A protected self-service admin interface
- Mixpanel with exactly the approved six events: `portfolio_viewed`, `case_study_opened`, `case_section_viewed`, `case_study_completed`, `high_intent_action` and `case_section_engaged` (active section exposure; currently only the two hardcoded case studies). Do not add others without approval

Follow these sources:
1. `/docs/product-requirements.md`
2. `/docs/portfolio-tracking-spec.md`
3. `/docs/design-reference.png`

Written requirements take precedence over the design image.

Do not write implementation code until the proposed architecture is approved.
